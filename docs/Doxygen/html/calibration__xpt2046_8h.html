Apply current touch calibration to a raw (x,y) reading.

If no valid calibration is available, the raw coordinates are clamped to the display bounds. Otherwise, an affine transform is applied:

x' = xA*x + xB*y + xC
y' = yA*x + yB*y + yC
Parameters
raw_xRaw X from controller.
raw_yRaw Y from controller.
[out]out_pointOutput LVGL point (screen space).
xmaxScreen width (max X, exclusive).
ymaxScreen height (max Y, exclusive).

void calibration_load_cal_data ( bool * calibration_found)

Load touch calibration data from NVS and indicate whether it was found.

This function attempts to read previously saved touch calibration data from NVS. It checks if valid calibration data exists and updates the provided flag accordingly. If no calibration is found, the system will print a message indicating that a new calibration is required.

Parameters
[out]calibration_foundPointer to a boolean that will be set to true if valid calibration data was found, or false otherwise.
Note
This function relies on the touch calibration subsystem and should be called after init_nvs() and touch driver initialization.

◆ calibration_run_cal()

esp_err_t calibration_run_cal ( bool calibration_found)

Run touch screen calibration if needed or requested by the user.

This helper checks whether a valid calibration was previously found and either:

  • runs the 5-point calibration immediately if calibration_found is false, or
  • asks the user (via a yes/no LVGL dialog) whether to run calibration again if calibration_found is true.

Behavior:

  • If no calibration is found: calls run_5point_touch_calibration().
  • If calibration exists:
    • On "Yes": runs run_5point_touch_calibration().
    • On "No" : keeps the existing calibration (s_cal) and clears the active LVGL screen.

UI objects used during the prompt are created and cleaned up internally.

Parameters
[in]calibration_foundTrue if a valid calibration was loaded from NVS, false if no calibration data is available.
Note
User prompt behavior:
  • When the loader is enabled (see calibration_set_show_loader), the Yes/No dialog auto-confirms "Yes" after 10 seconds.
  • When the loader is disabled (Settings flow), there is no countdown and the function waits for an explicit Yes/No.
Returns
ESP_OK Calibration flow completed successfully (either run or skipped by user).
Other esp_err_t codes If run_5point_touch_calibration() fails.
