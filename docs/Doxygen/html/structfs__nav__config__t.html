Detailed Description

Navigator configuration.

root_path must be an absolute directory path (trailing slashes are trimmed). max_items controls when sorting keeps all items in memory:

  • 0 enables sorting for any directory size (potentially large allocations).
  • >0 enables sorting only when item count <= max_items; above that, sorting is disabled and only windows are loaded.
