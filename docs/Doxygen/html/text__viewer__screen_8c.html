◆ text_viewer_open()

esp_err_t text_viewer_open ( const text_viewer_open_opts_t * opts)

Load the viewer screen and display the requested file.

Reads the file at opts->path, builds the screen (on first use), sets edit/view mode, populates the text area and status, and loads the screen. Original content is snapshotted to support dirty tracking.

Parameters
[in]optsOptions:
  • path: full path to the text file to view/edit (omit or empty for new files)
  • directory: parent directory used when path is NULL/empty
  • suggested_name: default filename populated when creating a new file
  • return_screen (required): screen to return to on close
  • editable: true to enable edit mode
  • on_close: optional callback invoked on close
  • user_ctx: user context for the close callback
Returns
  • ESP_OK on success
  • ESP_ERR_INVALID_ARG if required options are missing
  • fs_text_read_range error codes if reading fails
