◆ fs_text_append()

esp_err_t fs_text_append ( const char * path,
const char * data,
size_t len )

Append binary/text data to an existing file (or create if missing).

Opens path in append mode and writes exactly len bytes from data to the end of the file. If the file does not exist, a new one is created.

Parameters
pathAbsolute or relative path to the target file.
dataPointer to the data buffer to append.
lenNumber of bytes to write.
Return values
ESP_OKData appended successfully.
ESP_ERR_INVALID_ARGInvalid path or NULL data pointer.
ESP_FAILFile could not be opened or write failed.
Note
The file is opened in binary mode ("ab" or "wb"), suitable for both text and raw data. Data is flushed and file closed before returning.
Warning
If insufficient storage is available, partial writes may occur before failure is detected.

Create a new empty file.

Attempts to create a new file at path. If the file already exists, returns ESP_ERR_INVALID_STATE. The file is opened in binary write mode and immediately closed to ensure it exists and is empty.

Parameters

ESP_ERR_INVALID_ARGInvalid or unsafe path.
ESP_ERR_INVALID_STATEFile already exists.
ESP_FAILCreation failed (e.g. permission or I/O error).
Note

esp_err_t fs_text_read_range ( const char * path,
size_t offset_kb,
char ** out_buf,
size_t * out_len )

Read a fixed-size block of text bytes from a file starting at a given offset.

This function reads a chunk of data (FS_TEXT_READ_CHUNK_SIZE_B bytes) from a file, starting at an offset specified in kilobytes. It validates the file path, ensures the offset does not exceed the file size, adjusts the read length when near EOF, and allocates a null-terminated buffer for the output.

The caller takes ownership of the allocated buffer and must free it.

Parameters
[in]pathAbsolute file path to read from.
[in]offset_kbOffset in kilobytes from the start of the file. The actual byte offset becomes offset_kb * 1024.
[out]out_bufPointer to a char* that will receive the allocated buffer. Must not be NULL.
[out]out_lenOptional pointer to receive the number of bytes actually read. Can be NULL.
Returns
  • ESP_OK On success.
  • ESP_ERR_INVALID_ARG If parameters are invalid or the path fails validation.
  • ESP_ERR_INVALID_SIZE If the requested read size exceeds FS_TEXT_MAX_BYTES.
  • ESP_ERR_NO_MEM If memory allocation fails.
  • ESP_FAIL If file operations (stat, fopen, fseek, fread) fail.
Note
  • The output buffer is always null-terminated, even when reading binary data.
  • If the offset lands beyond EOF, a zero-length read is performed.
  • FS_TEXT_READ_CHUNK_SIZE_B defines the number of bytes to read per call.
  • The function only works with regular files.

◆ fs_text_write()

esp_err_t fs_text_write ( const char * path,
const char * data,
size_t len )

Atomically replace (or create) a text file with the provided buffer.

Writes the buffer to a temporary file in the same directory and renames it over path. When running on case-insensitive filesystems (e.g., FAT), an existing file is removed before the rename to ensure the case-only rename succeeds.

Parameters
pathAbsolute path to the .txt file.
dataBuffer to write (can be NULL if len == 0).
lenNumber of bytes from data to write.
Returns
ESP_OK on success, ESP_ERR_INVALID_ARG on bad params, ESP_ERR_INVALID_SIZE if path is too long, ESP_FAIL on filesystem errors.
