esp_err_t sntp_initialize ( void )

Initialize SNTP, set timezone, and wait for synchronization.

Starts SNTP, applies the default timezone from SNTP_DEFAULT_TIMEZONE, and waits up to 10 seconds for time to become valid.

Returns
ESP_OK on success or an esp_err_t from SNTP init/sync.

◆ sntp_wait_for_time_blocking()

esp_err_t sntp_wait_for_time_blocking ( uint32_t timeout_ms)

Block until time is synced or a timeout elapses.

Polls SNTP sync status in 1s steps up to timeout_ms and validates the resulting time against a minimum year. Returns ESP_ERR_TIMEOUT on failure.

Parameters
timeout_msMaximum wait in milliseconds.
Returns
ESP_OK if time is valid, ESP_ERR_TIMEOUT otherwise.
