◆ file_manager_start()

esp_err_t file_manager_start ( void )

Create the LVGL file-browser screen using the default SDSPI root.

Initializes the internal navigation context with CONFIG_SDSPI_MOUNT_POINT, builds the LVGL widgets, and loads the screen. The SD card must already be mounted via sd_card_init().

Returns
  • ESP_OK on success
  • ESP_ERR_INVALID_ARG if CONFIG_SDSPI_MOUNT_POINT is NULL
  • Errors propagated from fs_nav_init
  • ESP_ERR_TIMEOUT if the LVGL display lock cannot be acquired
