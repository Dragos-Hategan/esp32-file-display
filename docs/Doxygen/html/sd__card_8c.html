◆ sd_card_init()

esp_err_t sd_card_init ( void )

Initialize (or reinitialize) the SDSPI bus and mount the SD card filesystem.

Performs SPI bus setup and mounts FAT at CONFIG_SDSPI_MOUNT_POINT via esp_vfs_fat_sdspi_mount. If a card is already mounted or the bus is active, they are gracefully unmounted/freed before attempting again.

Returns
esp_err_t
  • ESP_OK on success
  • ESP-IDF error code if SPI bus initialization or FAT mount fails
