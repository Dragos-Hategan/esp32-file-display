◆ fs_nav_init()

esp_err_t fs_nav_init ( fs_nav_t * nav,
const fs_nav_config_t * cfg )

Initialize a navigator rooted at cfg->root_path and load persisted state if present.

Trims trailing slashes, validates root is an absolute directory, restores last relative path, sort mode and direction from NVS (best effort), then performs an initial directory scan.

Parameters
[out]navNavigator instance to initialize.
[in]cfgConfiguration (root path and item cap).
Returns
  • ESP_OK on success
  • ESP_ERR_INVALID_ARG on null args or invalid root path
  • ESP_ERR_NOT_FOUND if root is not accessible
  • Errors from fs_nav_refresh on initial scan failure

◆ fs_nav_items()

const fs_nav_item_t * fs_nav_items ( const fs_nav_t * nav,
size_t * count )

Get a pointer to the currently loaded items window.

When sorting is enabled, returns a slice starting at window_start of length up to window_size. When sorting is disabled, returns the last window loaded via fs_nav_set_window().

Parameters
[in]navNavigator.
[out]countOptional; set to number of valid items in the window.
Returns
Pointer to internal array (NULL if unavailable).
Warning
The pointer becomes invalid after fs_nav_refresh, fs_nav_set_window or sort changes.
Note
Item names are owned by the navigator and freed on refresh/deinit; do not free/mutate them.

◆ fs_nav_refresh()

esp_err_t fs_nav_refresh ( fs_nav_t * nav)

Rescan the current directory and refresh navigator state.

Computes total_items. If total_items <= max_items (or max_items==0), sorting stays enabled and all items are loaded/sorted. Otherwise, sorting is disabled and only the first window is loaded; additional windows must be fetched via fs_nav_set_window().

Parameters
[in,out]navNavigator.
Returns
  • ESP_OK on success
  • ESP_ERR_INVALID_ARG if nav is NULL
  • ESP_FAIL if directory cannot be opened
  • ESP_ERR_NO_MEM if allocation fails

◆ fs_nav_set_window()

esp_err_t fs_nav_set_window ( fs_nav_t * nav,
size_t start,
size_t size )

Set the current window (offset + size) to load for the directory listing.

When sorting is enabled (item count <= max_items), only the view window is adjusted. When sorting is disabled (item count > max_items or max_items==0), this will reload just the requested window from the filesystem without holding all items.

Parameters
navNavigator.
startZero-based offset into the directory items.
sizeNumber of items to load (must be >0).
Returns
ESP_OK on success; ESP_ERR_INVALID_ARG on bad params; ESP_FAIL on I/O errors; ESP_ERR_NO_MEM on allocation failure.
