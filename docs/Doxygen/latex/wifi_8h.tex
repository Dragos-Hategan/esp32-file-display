Initialize Wi-\/\+Fi in STA mode and wait for IP. 

This function\+:
\begin{DoxyEnumerate}
\item Initializes NVS storage (required for Wi-\/\+Fi).
\item Initializes the TCP/\+IP network stack and default event loop.
\item Creates the default Wi-\/\+Fi STA network interface.
\item Configures Wi-\/\+Fi parameters (SSID, password, auth mode, PMF).
\item Registers event handlers for Wi-\/\+Fi and IP events.
\item Starts the Wi-\/\+Fi driver and connects.
\item Blocks execution until an IP address is successfully obtained.
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
