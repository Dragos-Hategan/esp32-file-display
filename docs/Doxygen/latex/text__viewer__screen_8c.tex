Load the viewer screen and display the requested file. 

Reads the file at {\ttfamily opts-\/\texorpdfstring{$>$}{>}path}, builds the screen (on first use), sets edit/view mode, populates the text area and status, and loads the screen. Original content is snapshotted to support dirty tracking.


\begin{DoxyParams}[1]{Parameters}

\begin{DoxyItemize}
\item {\ttfamily path\+:} full path to the text file to view/edit (omit or empty for new files)
\item {\ttfamily directory\+:} parent directory used when {\ttfamily path} is NULL/empty
\item {\ttfamily suggested\+\_\+name\+:} default filename populated when creating a new file
\item {\ttfamily return\+\_\+screen} (required)\+: screen to return to on close
\item {\ttfamily editable\+:} true to enable edit mode
\item {\ttfamily on\+\_\+close\+:} optional callback invoked on close
\item {\ttfamily user\+\_\+ctx\+:} user context for the close callback
\end{DoxyItemize}\\
