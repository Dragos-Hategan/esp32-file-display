Initialize (or reinitialize) the SDSPI bus and mount the SD card filesystem. 

Performs SPI bus setup and mounts FAT at {\ttfamily CONFIG\+\_\+\+SDSPI\+\_\+\+MOUNT\+\_\+\+POINT} via {\ttfamily esp\+\_\+vfs\+\_\+fat\+\_\+sdspi\+\_\+mount}. If a card is already mounted or the bus is active, they are gracefully unmounted/freed before attempting again.

\item ESP\+\_\+\+OK on success
\item ESP-\/\+IDF error code if SPI bus initialization or FAT mount fails
