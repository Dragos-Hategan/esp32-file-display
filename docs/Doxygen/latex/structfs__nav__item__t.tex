\doxysubsection{Detailed Description}
Item metadata owned by the navigator. 

The {\ttfamily name} buffer is heap-\/allocated and freed internally on refresh/deinit; callers must not free or mutate it. {\ttfamily needs\+\_\+stat} is set when metadata is pending a stat call (e.\+g., during lazy loading).
