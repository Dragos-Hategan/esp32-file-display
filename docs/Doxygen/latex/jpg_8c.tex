Open a simple viewer screen that displays a JPEG file. 

The viewer builds a new LVGL screen with a close button and an image widget whose source is the provided {\ttfamily path}. On close, it returns to {\ttfamily return\+\_\+screen} if provided; otherwise it loads the previously active screen.

Must be called from the LVGL/task context that owns the display lock.
