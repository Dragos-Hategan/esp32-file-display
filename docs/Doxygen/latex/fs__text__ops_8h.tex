Read a fixed-\/size block of text bytes from a file starting at a given offset. 

This function reads a chunk of data (FS\+\_\+\+TEXT\+\_\+\+READ\+\_\+\+CHUNK\+\_\+\+SIZE\+\_\+B bytes) from a file, starting at an offset specified in kilobytes. It validates the file path, ensures the offset does not exceed the file size, adjusts the read length when near EOF, and allocates a null-\/terminated buffer for the output.

The caller takes ownership of the allocated buffer and must free it.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em path} & Absolute file path to read from. \\
\hline
\mbox{\texttt{in}}  & {\em offset\+\_\+kb} & Offset in kilobytes from the start of the file. The actual byte offset becomes {\ttfamily offset\+\_\+kb \texorpdfstring{$\ast$}{*} 1024}. \\
\hline
\mbox{\texttt{out}}  & {\em out\+\_\+buf} & Pointer to a char\texorpdfstring{$\ast$}{*} that will receive the allocated buffer. Must not be NULL. \\
\hline
\mbox{\texttt{out}}  & {\em out\+\_\+len} & Optional pointer to receive the number of bytes actually read. Can be NULL.\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}

\begin{DoxyItemize}
\item ESP\+\_\+\+OK On success.
\item ESP\+\_\+\+ERR\+\_\+\+INVALID\+\_\+\+ARG If parameters are invalid or the path fails validation.
\item ESP\+\_\+\+ERR\+\_\+\+INVALID\+\_\+\+SIZE If the requested read size exceeds FS\+\_\+\+TEXT\+\_\+\+MAX\+\_\+\+BYTES.
\item ESP\+\_\+\+ERR\+\_\+\+NO\+\_\+\+MEM If memory allocation fails.
\item ESP\+\_\+\+FAIL If file operations (stat, fopen, fseek, fread) fail.
\end{DoxyItemize}
\end{DoxyReturn}
\begin{DoxyNote}{Note}

\begin{DoxyItemize}
\item The output buffer is always null-\/terminated, even when reading binary data.
\item If the offset lands beyond EOF, a zero-\/length read is performed.
\item FS\+\_\+\+TEXT\+\_\+\+READ\+\_\+\+CHUNK\+\_\+\+SIZE\+\_\+B defines the number of bytes to read per call.
\item The function only works with regular files. 
\end{DoxyItemize}
\end{DoxyNote}
