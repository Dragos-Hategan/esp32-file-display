esp\+\_\+err\+\_\+t touch\+\_\+init (\begin{DoxyParamCaption}\item[{void}]{}{}\end{DoxyParamCaption})}



Initialize the SPI bus and the XPT2046 touch driver. 

This function sets up the SPI bus used by the XPT2046 touch controller, creates the {\ttfamily esp\+\_\+lcd\+\_\+panel\+\_\+io} handle, and initializes the XPT2046 touch driver through the {\ttfamily esp\+\_\+lcd\+\_\+touch} API. ~\newline
 It also applies orientation flags such as axis swap and mirroring according to the configuration macros ({\ttfamily TOUCH\+\_\+\+SWAP\+\_\+\+XY}, {\ttfamily TOUCH\+\_\+\+MIRROR\+\_\+X}, {\ttfamily TOUCH\+\_\+\+MIRROR\+\_\+Y}).

If the function is called multiple times, initialization will only be performed once. On success, a global handle to the touch driver is stored internally and can be retrieved later using {\ttfamily \doxylink{touch__xpt2046_8h_aaaeca84ff6624ca13980f74263d49a20}{touch\+\_\+get\+\_\+handle()}}.

\begin{DoxyReturn}{Returns}

\begin{DoxyItemize}
\item ESP\+\_\+\+OK on successful initialization ~\newline

\item Error code from underlying ESP-\/\+IDF driver functions if initialization fails ~\newline
 (for example\+: {\ttfamily ESP\+\_\+\+ERR\+\_\+\+NO\+\_\+\+MEM}, {\ttfamily ESP\+\_\+\+ERR\+\_\+\+INVALID\+\_\+\+ARG}, etc.)
\end{DoxyItemize}
\end{DoxyReturn}
\begin{DoxyNote}{Note}
The SPI bus is initialized with automatic DMA channel selection. 

The XPT2046 interrupt pin is expected to be active-\/low. 

The recommended SPI clock for XPT2046 is typically \texorpdfstring{$\sim$}{\string~}2.5 MHz. 
\end{DoxyNote}
